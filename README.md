# Bring the Lab Home

Public R&D portfolio and lab-recovery campaign for Jason A. Hayes.

## Purpose

The site presents a concise record of applied research and systems-development work, including:

- the Washington R&D lab;
- embedded computing and Linux;
- networking and PoE infrastructure;
- geospatial and location-derived systems;
- cloud and distributed-systems research;
- field operations and practical product development.

The recovery campaign has a **$10,000** target to recover the Washington lab equipment, transport it to Tennessee, inventory and clean it, perform controlled recommissioning, and return it to useful R&D service.

## Site

This repository contains a lightweight static site published through GitHub Pages.

- `index.html` contains the public page structure and content.
- `styles.css` contains the responsive visual system.
- `config.js` contains the public campaign, repository, and share URLs.
- `app.js` handles sharing and campaign-link wiring.
- `assets/` contains the public page photography and supporting files.

## Support

The public support button opens the configured PayPal contribution page. GitHub Pages does not collect or process payment information.

Contributions are presented as support for the lab-recovery mission and are not advertised as tax-deductible donations.
